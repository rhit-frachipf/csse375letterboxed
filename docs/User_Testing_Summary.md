# CSSE375 User Testing Report

## Instructions Given to Testers
- Create an account.
- Look up and add 2 movies to your watchlist.
- Look up and rate and review 2 movies.
- Look up and follow the user "Peterfrach".
- Change your privacy settings.
- Log out and log back in.
- Remove a movie from your watchlist.

## Test 1
- User: Keeley Wilhelm
- Notes:
	- People might search for users in the movie search prompt.
	- Saving reviews requires text input and a button click, which could be improved.
	- Clicking on the star rating auto-saves the rating, which is not made clear to the user.
- Feedback:
	- Instead of a toggle watchlist button, use explicit Add to Watchlist / Remove from Watchlist buttons.
