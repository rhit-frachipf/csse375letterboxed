Objective 4
The primary code smells addressed were structural:
Backend issues:
Temporary Field / Inappropriate Intimacy / Primitive Obsession
(global user/login state on Flask app)
Feature Envy
(routes manipulating nested data directly)
Frontend issues:
Large Class / Divergent Change (scripts.js)
Duplicated Code (fetch + rendering logic)
Data Clumps / Primitive Obsession (movie data representation)
Solutions implemented:
Moved to session-based state handling
Introduced repository + service abstractions
Split frontend into smaller modules
Extracted shared helpers
Updated tests to match new structure
