# Demo and Delivery Checklist

## 1. System Demonstration Plan
- Demo login/signup and session behavior.
- Demo movie search and suggestions.
- Demo watchlist and watched rating/review updates.
- Demo user discovery, follow/unfollow, and activity feed.
- Demo privacy settings effect on profile visibility.
- Demo CI workflow presence and test automation setup.

## 2. Delivery Package Contents
- Source code repository with backend/frontend code.
- `docs/` with Milestone 4 and Objective 1 deliverables.
- CI workflow in `.github/workflows/ci.yml`.
- Test suite in `tests/`.
- Setup instructions in README and installation guide.

## 3. Final Delivery Validation
- Confirm backend tests pass.
- Confirm frontend tests execute in CI environment.
- Confirm all required Objective 1 documents are present in `docs/`.
