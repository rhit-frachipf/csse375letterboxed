# User Guide

## 1. Getting Started
1. Open the app and create an account on the signup page.
2. Log in using your account credentials.
3. Use navigation buttons to open Search, My Movies, Watchlist, Find User, and Settings.

## 2. Core Workflows
- Search movies from the Search page.
- Open a movie page to view details and add it to your watchlist.
- Save a rating/review for watched movies.
- Open My Movies to view rated/reviewed movies.
- Use Find User to look up profiles and follow/unfollow.
- Open Friends page to view activity feed from followed users.
- Use Settings to update username/password and privacy toggles.

## 3. Privacy Behavior
If another user disables a visibility option, their hidden content will not appear on profile or activity views.

## 4. Known Limits
- Ratings/reviews visibility depends on user privacy settings.
- Some operations require login and will fail when session is missing.
